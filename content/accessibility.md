---
title: Accessibility
description: Accessibility statement for the Bodmin Lions Club website.
---
We want everyone to be able to use this website. It aims to meet [WCAG 2.2](https://www.w3.org/TR/WCAG22/) level AA. You should be able to:

- zoom to 400% without content being cut off
- use the whole site with a keyboard
- use it with a screen reader
- read it in light or dark mode

**Known issues:** some older PDF forms aren't fully accessible. If you need any information in a different format, email [bodmin.lions@outlook.com](mailto:bodmin.lions@outlook.com) and we'll help.
